# 3D · AR 공간 배치

## 현재 동작

- `/space?artwork=sculpture`에서 작품을 선택하고, 가상 공간의 위치·회전·비교 크기를 조절한다. 모델은 등록한 cm 치수를 미터로 변환하며 바닥 중심을 원점으로 사용한다.
- 첨부 GLB가 있으면 해당 모형을 사용한다. 기본 조소·도자 4점은 사진을 참고한 형태·재질 스터디이며 스캔 결과가 아니다. 모형이 없는 작품은 등록 사진 패널을 사용한다.
- WebGL 실패 시 오류를 안내하고, 화면을 떠날 때 렌더러·텍스처·이벤트를 정리한다.

## 이슈 #4: 실제 벽 배치 구현

- 지원 기기에서 사용자가 버튼을 눌렀을 때만 WebXR `immersive-ar` 세션과 `hit-test`, `dom-overlay` 권한을 요청한다.
- `mounting=wall`인 작품은 **수직 벽의 hit-test 결과만** 받는다. 바닥을 대신 벽으로 취급하지 않는다. 세로 벽을 찾으면 표식에 작품 중심을 맞춰 **여기에 걸기**로 배치한다.
- WebXR hit-test 행렬의 Y축을 표면 법선으로 사용한다. 벽은 정규화한 법선의 `abs(y) <= 0.25`, 바닥·테이블은 `y >= 0.85`를 통과해야 한다. 천장이나 잘못된 방향의 표면은 거절한다.
- 그림의 앞면을 벽 법선과 정렬하고, 벽 안의 위쪽 방향을 중력의 반대 방향으로 맞춘다. 따라서 카메라를 옆으로 움직여도 그림이 카메라를 따라 돌아가지 않는다.
- hit 위치는 그림의 **중심**이다. 모델의 바닥 원점을 등록 높이의 절반만큼 내려 보정하고, 작품 뒷면은 검출 벽 앞 4mm에 둔다. 이 4mm는 겹쳐 보이는 현상을 줄이는 표시 여유이며 설치 거리 측정값이 아니다.
- AR에서는 비교 크기 슬라이더와 관계없이 등록 크기 100%를 사용한다. 벽에 배치한 뒤 2cm씩 좌우·높이를 조절하거나, 조절을 초기화하거나, 다른 벽을 비춰 다시 배치할 수 있다. 조절 범위는 첫 배치 위치에서 각 축 ±50cm다.
- 벽을 10초 이상 찾지 못하면 조명·벽 무늬·기기 지원에 대한 안내를 보여준다. 표면을 잃으면 배치 및 조절 버튼을 비활성화한다. 350ms보다 오래된 위치로는 새 배치를 확정하지 않는다.
- 세션 가시성이 바뀌면 후보 위치를 지운다. 공간 기준 좌표가 초기화되면 기존 배치를 숨기고 다시 배치하도록 안내한다. **AR 종료** 또는 시스템 종료 후에는 가상 공간과 원래 시점·크기를 복원한다.
- 앱은 카메라 영상을 업로드하거나 저장하지 않는다.

## 자동 검증

```powershell
cd frontend
node --test tests/spatial-dimensions.test.mjs tests/ar-placement.test.mjs
pnpm typecheck
pnpm build
```

기존 모델 치수 검사 2개와 AR 검사 8개를 사용한다.

- 벽·바닥·천장·경사면의 구분, 반대 법선 방향 처리
- 벽과 평행한 방향, 카메라 이동 시 방향 유지
- 등록 높이 기반 중심 보정, 뒷면과 벽 사이 거리, 깊이가 0인 사진 패널
- 벽 면을 벗어나지 않는 좌우·높이 조절, 조절 한도
- 기존 탁자 배치의 바닥 중심 원점
- 잘못된 행렬·치수 거절, 오래되거나 가려진 추적 결과 거절

이 검사는 좌표 계산과 배치 조건을 확인한다. 실제 카메라 인식률이나 크기 오차를 증명하지 않는다.

## 실기기 확인 — 아직 미실행

**실제 WebXR 휴대폰이 없어 이슈 #4의 실기기 완료 기준은 미완료다.** 코드 구현 PR을 병합하더라도 이슈의 촬영·탁자 회귀검사 항목은 결과가 기록될 때까지 체크하지 않는다.

HTTPS로 배포한 주소에서 아래를 확인하고 기종·OS·브라우저 버전·일시·사진/영상 경로를 기록한다. 모바일 localhost는 그 휴대폰 자체이므로 PC의 로컬 서버 주소로는 확인할 수 없다.

| 시나리오 | 확인할 결과 | 현재 결과 |
| --- | --- | --- |
| 40×50cm 등 실측 기준이 있는 회화, 벽 정면 | 벽과 평행하고 표식이 작품 중심에 위치 | 미실행 |
| 같은 그림을 좌우·비스듬한 각도에서 촬영 | 그림이 관찰자를 따라 회전하지 않음 | 미실행 |
| 높이·좌우 조절, 초기화, 다른 벽으로 재배치 | 2cm 조절과 새 위치 반영, 크기 유지 | 미실행 |
| 바닥만 비추기, 무늬 없는 벽, 어두운 곳 | 벽 배치 거절 및 재시도 안내 | 미실행 |
| 조소를 탁자·바닥에 배치 | 기존 수평면 기능과 등록 치수 유지 | 미실행 |
| 권한 거절·추적 손실·백그라운드 복귀·종료 | 잘못된 위치 확정 방지, 가상 공간 복원 | 미실행 |
| 실제 크기·높이 대조 | 가로·세로·위치 오차를 cm와 %로 기록 | 미실행 |

## 남은 제한

- 이 구현은 WebXR이 반환한 평면과 추정 좌표를 사용한다. 실제 벽 인식 지원과 정확도는 기기·조명·표면에 따라 달라진다. 방향을 제공하지 않는 런타임은 표면 법선을 위쪽으로 반환할 수 있어 벽 배치가 활성화되지 않는다.
- 벽 경계·문·창문·주변 가구를 검증하지 않는다. 조절한 그림이 벽 모서리를 넘지 않았는지 사용자가 확인해야 한다. 실제 설치 전 치수와 지지면을 따로 확인한다.
- AR anchor를 고정 저장하거나 장기 위치 정확도를 보장하지 않는다. 환경 차폐·조명 추정·여러 작품 동시 배치·iOS Quick Look/USDZ 경로는 별도 개발 대상이다.
