# 3D · AR 공간 배치

## 현재 동작

- `/space?artwork=sculpture`에서 작품을 선택하고, 가상 공간의 위치·회전·비교 크기를 조절한다. 모델은 등록한 cm 치수를 미터로 변환하며 바닥 중심을 원점으로 사용한다.
- 첨부 GLB가 있으면 해당 모형을 사용한다. 기본 조소·도자 4점은 사진을 참고한 형태·재질 스터디이며 스캔 결과가 아니다. 모형이 없는 작품은 등록 사진 패널을 사용한다.
- WebGL 실패 시 오류를 안내하고, 화면을 떠날 때 렌더러·텍스처·이벤트를 정리한다.

## 이슈 #4: 실제 벽 배치 구현

- 지원 기기에서 사용자가 버튼을 눌렀을 때만 WebXR `immersive-ar` 세션과 `hit-test`, `dom-overlay` 권한을 요청한다.
- `mounting=wall`인 작품은 **수직 벽의 hit-test 결과만** 받는다. 바닥을 대신 벽으로 취급하지 않는다. 표면 관찰이 연속 800ms 안정적이고 카메라와 배치점의 거리가 0.25–4m 범위일 때 배치를 허용한다. 세로 벽에서 준비 상태가 되면 표식에 작품 중심을 맞춰 **여기에 걸기**로 배치한다. 이 조건은 불안정한 배치를 줄이는 경험적 기준이며 실측 정확도나 신뢰 확률이 아니다.
- WebXR hit-test 행렬의 Y축을 표면 법선으로 사용한다. 벽은 정규화한 법선의 `abs(y) <= 0.25`, 바닥·테이블은 `y >= 0.85`를 통과해야 한다. 천장이나 잘못된 방향의 표면은 거절한다.
- 그림의 앞면을 벽 법선과 정렬하고, 벽 안의 위쪽 방향을 중력의 반대 방향으로 맞춘다. 따라서 카메라를 옆으로 움직여도 그림이 카메라를 따라 돌아가지 않는다.
- hit 위치는 그림의 **중심**이다. 모델의 바닥 원점을 등록 높이의 절반만큼 내려 보정하고, 작품 뒷면은 검출 벽 앞 4mm에 둔다. 이 4mm는 겹쳐 보이는 현상을 줄이는 표시 여유이며 설치 거리 측정값이 아니다.
- AR에서는 비교 크기 슬라이더와 관계없이 등록 크기 100%를 사용한다. 벽에 배치한 뒤 2cm씩 좌우·높이를 조절하거나 조절을 초기화할 수 있다. 조절 범위는 첫 배치 위치에서 각 축 ±50cm다. **다시 배치**는 기존 배치를 해제하고 표면 탐색으로 돌아가는 동작이다. 새 위치가 안정화되면 다시 확정한다.
- 벽을 10초 이상 찾지 못하면 조명·벽 무늬·기기 지원에 대한 안내를 보여준다. 새 배치는 유효하고 안정적인 표면 후보가 있을 때만 가능하며, 오래되거나 끊긴 추적 결과로 확정하지 않는다.
- 런타임이 지원하면 배치한 위치에 anchor를 만들어 현재 세션의 위치 유지를 보조한다. 미지원 또는 생성 실패 시 해당 상태를 표시하고 지원 가능한 배치 방식으로 진행한다. 세션 종료 후 공간을 기억하거나 위치를 복구하는 저장 기능은 아니다.
- 세션 가시성이 바뀌면 후보 위치를 지운다. 공간 기준 좌표가 초기화되면 기존 배치를 숨기고 다시 배치하도록 안내한다. **AR 종료** 또는 시스템 종료 후에는 가상 공간과 원래 시점·크기를 복원한다.
- 불투명한 종료 버튼과 스크롤 가능한 상태·조작 카드, 안정화 진행 표시 및 접을 수 있는 진단 정보를 제공한다. AR을 끝낸 뒤에도 마지막 세션의 진단 기록을 내려받을 수 있다. 앱은 카메라 영상이나 사진을 수집·업로드하지 않는다.

## 자동 검증

```powershell
cd frontend
node --test tests/spatial-dimensions.test.mjs tests/ar-placement.test.mjs tests/ar-tracking.test.mjs
pnpm typecheck
pnpm build
```

모델 치수와 AR 배치 조건의 자동 검사를 사용한다. 검사 개수와 실행 결과는 해당 변경의 CI 기록으로 확인한다.

- 벽·바닥·천장·경사면의 구분, 반대 법선 방향 처리
- 벽과 평행한 방향, 카메라 이동 시 방향 유지
- 등록 높이 기반 중심 보정, 뒷면과 벽 사이 거리, 깊이가 0인 사진 패널
- 벽 면을 벗어나지 않는 좌우·높이 조절, 조절 한도
- 기존 탁자 배치의 바닥 중심 원점
- 잘못된 행렬·치수 거절, 오래되거나 가려진 추적 결과 거절
- 연속 관찰 시간·거리·표면 흔들림에 따른 배치 준비 상태 전환

이 검사는 좌표 계산과 배치 조건을 확인한다. 실제 카메라 인식률이나 크기 오차를 증명하지 않는다.

## 사용자 1차 확인과 재검증

**2026-11-11 Galaxy S26 Ultra의 Chrome에서 사용자 1차 테스트가 있었다.** 서로 다른 바닥 배치에서 크기가 일관되지 않게 보였고 무늬 없는 벽 배치가 되지 않았다는 보고다. 사용자는 1번과 4번 사진이 각각 새로 배치한 결과라고 확인했으므로, 두 사진의 차이를 동일 배치에서 카메라만 이동한 사례로 해석하지 않는다. 정확한 OS·브라우저 버전과 실측 오차는 미기록이며, 특정 크기 오차율이 측정된 것으로 간주하지 않는다. 수정 후 실기기 재검증은 아직 수행하지 않았다.

이슈 #4의 실기기 완료 기준은 계속 미완료로 둔다. [재검증 절차와 기록표](ar-device-validation.md)에 따라 청동 작품 20×34×15cm, 단단한 기준면의 바닥 윤곽 및 34cm 수직 기준물을 사용한다. 같은 위치에 새로 배치하는 시험과 한 번 배치한 뒤 카메라를 움직이는 시험을 구분한다. 무늬 있는 종이를 임시 부착한 벽과 무늬 없는 벽도 별도로 기록한다.

HTTPS로 배포한 주소에서 기종·OS·브라우저 버전·일시·배포 버전과 진단 기록을 남긴다. 사용자 사진이나 로컬 첨부 경로는 저장소에 포함하지 않는다. 모바일 localhost는 그 휴대폰 자체이므로 PC의 로컬 서버 주소로는 확인할 수 없다.

## 남은 제한

- 이 구현은 WebXR이 반환한 평면과 추정 좌표를 사용한다. 실제 벽 인식 지원과 정확도는 기기·조명·표면에 따라 달라진다. 방향을 제공하지 않는 런타임은 표면 법선을 위쪽으로 반환할 수 있어 벽 배치가 활성화되지 않는다.
- 벽 경계·문·창문·주변 가구를 검증하지 않는다. 조절한 그림이 벽 모서리를 넘지 않았는지 사용자가 확인해야 한다. 실제 설치 전 치수와 지지면을 따로 확인한다.
- 세션 내 anchor가 지원되더라도 영구 공간 저장이나 장기 위치 정확도를 보장하지 않는다. 안정화 시간과 거리 조건을 통과해도 추적 오차가 남을 수 있다. 환경 차폐·조명 추정·여러 작품 동시 배치·iOS Quick Look/USDZ 경로는 별도 개발 대상이다.
